# Rock, Paper, Scissors Game
This is the very known game Rock Paper Scissors. You play with the computer for 5 rounds. You will have to enter your choice and you will get the results for each
round and the final score.
<br>
You can find the website here: https://claracanyis.github.io/rock-paper-scissors/
